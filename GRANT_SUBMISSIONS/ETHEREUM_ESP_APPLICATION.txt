PROJECT NAME
SolarPunk Protocol

---

ONE-LINE SUMMARY
Open-source Ethereum testnet infrastructure for renewable-energy data, oracle hardening, and energy-linked settlement research.

---

SHORT DESCRIPTION

SolarPunk Protocol is an open-source Sepolia prototype exploring how public renewable-energy data can support transparent, auditable on-chain settlement and hedging primitives.

The project combines:

- source-verified Solidity contracts on Sepolia,
- a signed meter -> surplus attestation -> SPK mint proof on Sepolia,
- a read-only public proof readback confirming consumed attestation and source hashes,
- a daily NASA POWER -> Sepolia keeper experiment,
- a Python pricing and margin-analysis library,
- a React proof dashboard with live contract reads,
- audit-readiness, trust-assumption, invariant, and threat-model documentation.

SolarPunk is not presented as a production stablecoin, audited protocol, or mainnet financial product. The current contribution is public-good research infrastructure: it makes an energy-indexed settlement mechanism externally inspectable through code, public transactions, committed keeper artifacts, and reproducible documentation.

---

PROBLEM

Renewable-energy production is physically measurable but financially volatile. Weather, irradiance, curtailment, and regional electricity prices create revenue uncertainty, especially for smaller projects that cannot access institutional hedging infrastructure.

At the same time, most DeFi risk infrastructure is generic and speculative. It rarely connects settlement logic to real physical data, conservative basis-risk controls, or transparent oracle provenance.

The research question is whether Ethereum infrastructure can support an open, auditable prototype for energy-linked settlement that is useful for future renewable-energy finance pilots.

---

SOLUTION

SolarPunk builds a testnet proof surface for energy-linked settlement:

1. Registered meter devices sign raw renewable-energy readings.
2. The attestation pipeline verifies signatures, duplicate nonces, closed windows, quality thresholds, capacity bounds, and energy balance.
3. Accepted surplus is reduced to a deterministic source hash.
4. An oracle role signs the surplus amount, recipient, measurement window, validity window, chain ID, contract address, and source hash.
5. `SolarPunkCoin.mintFromSurplusAttestation` verifies the signature and replay guards before minting SPK.
6. NASA POWER irradiance data is also fetched daily and written to Sepolia through the older keeper path, keeping an independent real-data experiment running.

The protocol also includes:

- `SolarPunkCoin`: PI-controlled energy-indexed stablecoin prototype.
- `SolarPunkOption`: margin-based European settlement/clearinghouse prototype.
- `ProtocolTreasury`: fee vault and slashable role-bond escrow.
- `StabilityPool`: separated peg-stability vault.
- `ChainlinkOracleAdapter`: AggregatorV3Interface-compatible adapter with manual fallback.

The next funded phase would harden this prototype through external review, oracle productionization, L2 deployment analysis, and public reporting.

WHY THIS FITS ETHEREUM

SolarPunk uses Ethereum as a public verification layer for real-world data and settlement logic. The value to the Ethereum ecosystem is not a private trading product; it is open-source infrastructure and research showing how Ethereum can support non-speculative, real-world financial primitives.

Ethereum relevance:

- Public, source-verified smart contracts.
- Reproducible testnet evidence.
- Open oracle and settlement assumptions.
- L2 deployment analysis for low-cost recurring updates.
- Public reporting that can inform other oracle-dependent RWA and climate-finance projects.

ESP support would help convert a working prototype into a more credible public-good artifact: externally reviewed contracts, hardened oracle flow, documented L2 constraints, and a public technical report.
