# Global AI Finance 2026 — Portal / Owner Action Checklist

This file separates research packaging from personal/legal/financial actions that must not be guessed or silently consented to.

## Prepared without owner intervention

- [x] candidate title;
- [x] extended abstract;
- [x] keywords;
- [x] claim/evidence ledger;
- [x] author briefing;
- [x] reviewer Q&A;
- [x] acceptance-obligation brief;
- [x] poster storyboard;
- [x] overlap/ethics policy;
- [x] public evidence checkpoint and reproduction path.

## Owner-specific fields — must be confirmed from account/owner, not invented

- [ ] exact author name as it should appear in conference records;
- [ ] email address used for submission/notifications;
- [ ] affiliation wording;
- [ ] country/region and postal/contact fields required by ConfTool;
- [ ] coauthor list, if any;
- [ ] presenter identity;
- [ ] ORCID or other identifier if requested/desired;
- [ ] conflict-of-interest declarations if the form asks for them.

## Default affiliation rule

Do **not** imply that Yuan Ze University owns, sponsors, validates, or endorses Policy Lab merely because the author is a YZU student.

If an affiliation field is required, use accurate academic affiliation only. Keep project ownership/validation claims separate.

## Consent gates requiring owner action

Never silently accept on the owner's behalf:

- [ ] privacy/data-processing terms tied to personal account creation;
- [ ] originality/authorship declarations;
- [ ] copyright transfer or publication license;
- [ ] attendance/presentation commitment beyond what is already known;
- [ ] payment/registration charge;
- [ ] non-refundable fee;
- [ ] public release of additional personal details not necessary for the submission.

## Final portal verification before submit

- [ ] venue and year are correct;
- [ ] submission route is **work-in-progress poster**, not full paper;
- [ ] title exactly matches the frozen external artifact;
- [ ] abstract text exactly matches the frozen external artifact unless a portal character limit forces a separately reviewed adaptation;
- [ ] keywords fit portal limits;
- [ ] no accidental 'AI' category is selected merely because of conference branding;
- [ ] no pilot/customer/operator/adoption claim is introduced in free-text fields;
- [ ] no proceedings/publication language appears that creates an unreviewed overlap conflict with FC'27;
- [ ] any required upload is opened after upload to verify correct file/version;
- [ ] final preview/screenshot is saved;
- [ ] submission receipt / paper ID is saved after submit.

## Stop-and-escalate conditions

Stop before final submission if the portal unexpectedly requires:

- a full paper rather than an extended abstract;
- a copyright transfer;
- a registration payment at submission time;
- a commitment that conflicts with known availability;
- a declaration incompatible with active FC'27 plans;
- claims of AI contribution, institutional sponsorship, or external validation not present in the prepared artifact;
- a materially different public-release condition from the known poster/program route.

## After submit

Record in `SUBMISSION_MANIFEST.json` or a submission receipt record:

- submission ID;
- submission timestamp;
- exact title;
- exact uploaded/text artifact hash;
- listed author(s);
- listed affiliation(s);
- route/category;
- confirmation email/receipt location;
- any newly disclosed obligation or deadline.
