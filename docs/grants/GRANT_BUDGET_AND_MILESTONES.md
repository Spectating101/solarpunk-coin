# Grant Budget and Milestones

**Recommended primary ask:** **$48,000**  
**Minimum useful ask:** **$25,000**  
**Expanded pilot ask:** **$75,000-$100,000**, only if the program explicitly funds broader pilots.

## Why $48,000

$48k is large enough to unlock the next credible stage but not so large that it reads like unfocused runway. It maps to audit readiness, oracle hardening, frontend/demo/public proof, and a capped L2 pilot plan.

## Budget

| Category | Amount | Purpose |
|---|---:|---|
| Smart contract audit + remediation | $24,000 | External audit or contest/private review, finding triage, regression tests, remediation report. |
| Oracle productionization | $10,000 | Chainlink Automation / Functions prototype, NASA POWER fetch hardening, monitoring, stale-data handling. |
| L2 deployment + operations | $6,000 | Arbitrum/Optimism test deployment, gas, monitoring, alerting, runbooks, capped pilot execution. |
| Frontend/reviewer proof surface | $4,000 | Hosted demo, walkthrough video, public dashboard polish, documentation QA. |
| Research + reporting | $4,000 | Public technical report, thesis appendix updates, empirical/pilot analysis. |
| **Total** | **$48,000** | |

## Minimum Version: $25,000

If a program offers partial funding, ask them to fund:

- $20,000 audit/review
- $3,000 remediation/testing
- $2,000 public proof/reporting

This does not get SolarPunk to production, but it converts the largest blocker into a defined security milestone.

## Expanded Version: $75,000

Use only for programs that expect larger asks:

- $30,000 security audit/remediation
- $15,000 Chainlink oracle and automation migration
- $10,000 L2 deployment and monitoring
- $10,000 pilot/operator discovery and legal/compliance scoping
- $5,000 frontend/demo/reporting
- $5,000 research publication and conference/workshop output

## What Grant Funding Does Not Cover

Do not request ecosystem grants for solvency capital. Operational collateral/reserve capital should come from impact investors, development banks, pilot partners, or protocol-specific liquidity programs.

Use this wording:

> This grant does not fund solvency reserves or option-writer capital. Those are operational capital needs and will be raised separately. Grant funds are used for open-source infrastructure, audit, oracle hardening, and public reporting.

## 12-Week Milestone Plan

| Week | Milestone | Deliverable |
|---|---|---|
| 1-2 | Scope freeze | Audit scope tag, contract inventory, threat model update, invariant checklist final pass. |
| 3-5 | Audit / external review | Auditor engagement or contest launch, issue triage, public audit status page. |
| 6-7 | Remediation | Fixes, regression tests, updated audit-readiness packet, before/after report. |
| 8-9 | Oracle hardening | Chainlink Automation/Functions prototype, stale-data policy, monitoring alerts. |
| 10 | L2 pilot deployment | Arbitrum/Optimism test deployment with capped open-interest configuration. |
| 11 | Demo + reporting | Hosted dashboard, walkthrough video, public technical report draft. |
| 12 | Closeout | Final grant report, next-pilot readiness memo, updated evidence register. |

## 6-Month Milestone Plan

| Month | Milestone | Deliverable |
|---|---|---|
| 1 | Audit readiness + external review start | Scope tag, auditor handoff, review kickoff. |
| 2 | Audit fixes + oracle migration prototype | Remediation branch, Automation/Functions proof. |
| 3 | Risk-boxed L2 deployment | Capped deployment with documented parameters and emergency controls. |
| 4 | Pilot discovery | 5-10 operator/advisor conversations; at least 1 LOI or written feedback target. |
| 5 | Public technical report | Settlement/oracle report connecting thesis, live testnet, and pilot constraints. |
| 6 | Grant closeout + next funding decision | Final report, updated demo, decision on mainnet/pilot continuation. |

## Success Metrics

- Audit completed or external review report published.
- All critical/high findings fixed with tests.
- Daily keeper migrated or partially migrated to Chainlink Automation/Functions.
- Public frontend/demo URL available.
- Evidence register updated weekly during grant period.
- At least one external stakeholder signal: advisor note, operator call, ecosystem partner response, or non-deployer testnet interaction.
