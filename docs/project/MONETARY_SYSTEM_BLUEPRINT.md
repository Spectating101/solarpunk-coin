# Solarpunk Monetary System Blueprint

## What Solarpunk Is
Solarpunk is an energy-native crypto monetary protocol:
- issuance from verifiable energy surplus,
- intrinsic redemption path,
- solvency and stability controls on-chain.

## Standalone Functional Purpose
1. Convert verified energy output into programmable monetary units.
2. Keep value behavior bounded through peg/stability controls.
3. Enforce reserve/risk constraints before issuance can continue.
4. Provide derivatives settlement rails for hedging and liquidity.

## Build Strategy (Step-by-Step, Not Big-Bang)
1. Phase 0: Protocol Integrity (Now)
- Keep contracts/tests/verification green and reproducible.
- Exit condition: deterministic verification artifacts and readiness reports.

2. Phase 1: Controlled Monetary Pilot
- Small participant set, constrained issuance/redeem flows.
- Exit condition: no solvency incidents and stable control behavior under shocks.

3. Phase 2: Live Attestation Hardening
- Meter/energy attestation + oracle reliability hardening.
- Exit condition: auditable data path from physical energy to mint event.

4. Phase 3: Market Expansion
- Wider participant access and external integrations.
- Exit condition: repeatable operations without manual intervention bottlenecks.

## Immediate Rule
Do not claim "currency replacement" until Phase 2 is operationally proven.
Claim "energy-native monetary protocol pilot" until then.
