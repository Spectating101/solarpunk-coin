# Legacy Grant Submissions

This directory contains older grant drafts and sponsorship materials that are kept for reference only.

These files are not submission-ready. Several predate the current Sepolia proof surface, the hardened thesis framing, the working GitHub Pages demo URL, and the current grant strategy. They may contain stale or over-aggressive claims about market size, mainnet timing, chain selection, pilots, or production readiness.

For live submissions, use:

- `GRANT_SUBMISSIONS/CHAINLINK/BUILD_APPLICATION.md`
- `GRANT_SUBMISSIONS/ETHEREUM_ESP_APPLICATION.txt`
- `docs/grants/TOMORROW_SUBMISSION_BRIEF.md`
