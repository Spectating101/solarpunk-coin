# SolarPunk Pilot Commercial Packet

## Product Offer

SolarPunk turns renewable-energy production/export data into an SPK cryptocurrency mint preview, dashboard, and case-study report.

The first sellable version is not a public token launch. It is a paid research/demo/pilot service for labs, solar operators, universities, climate/Web3 sponsors, and energy researchers.

## What The Customer Gets

- Data intake using `scripts/operator_data_intake.js`.
- CSV/API validation and rejected-row report.
- Eligible surplus kWh calculation.
- SPK cryptocurrency mint preview.
- Provenance level: sample, operator CSV, live inverter/gateway, revenue-grade, or utility-corroborated.
- Public or private case-study markdown.
- Dashboard metric inside the SolarPunk frontend.
- Recommended path to closed testnet pilot.

## Pilot Packages

| Package | Price band | Buyer | Output |
|---|---:|---|---|
| Data-only case study | `$500-$1,500` | lab, professor, solar owner, sponsor | one dataset -> SPK preview + report |
| Weekly shadow pilot | `$1,500-$5,000/month` | campus, solar operator, ReFi/DePIN sponsor | repeated weekly processing + dashboard + cumulative report |
| Closed beta setup | `$7,500-$25,000` | funded operator or ecosystem sponsor | signed source, governed testnet deployment, monitoring, audit-ready packet |

These are service/research prices, not token sale terms.

## Boundary

The paid pilot sells analysis, integration, and proof generation. It does not sell investment returns, redeemable SPK, energy credits, RECs, or guaranteed income.

## Why This Matters

The current public lab proves the SPK mechanism. A paid pilot proves the missing market step: an external party is willing to provide data, use the system, and potentially fund the next security/legal/audit stage.

## Conversion Path

1. Run public sample through `npm run product:operator-intake`.
2. Get one external solar CSV.
3. Generate external SPK case study.
4. Offer weekly shadow pilot.
5. Move one operator to signed live inverter/gateway source.
6. Use pilot or grant money for security review.
7. Run closed testnet beta.
8. Only then reassess limited public SPK launch.
