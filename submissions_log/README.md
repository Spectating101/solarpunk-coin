# Submissions Log

Use this folder to track external submissions (SSRN, VoxEU, ITPF, AEDC, grants).

## Why
A lot of confusion comes from having draft files but no proof of upload.
This log is the source of truth for what was actually submitted.

## Files
- `tracker.csv`: one row per submission attempt
- `ENTRY_TEMPLATE.md`: copy this for detailed per-submission notes
- `artifacts/`: optional place for screenshots/PDF confirmations

## Minimum evidence to save each time
1. Submission date/time (local + UTC)
2. Venue/portal URL
3. Submission title exactly as uploaded
4. Submission ID / tracking number
5. Confirmation proof (screenshot or confirmation email export)
6. Final uploaded file list

## Rule
If it is not recorded here, treat it as not submitted.
