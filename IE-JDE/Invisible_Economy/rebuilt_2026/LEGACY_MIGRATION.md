# Invisible Ledger V2 — Legacy Migration Map

The old Invisible Ledger materials remain useful as a source archive, but they no longer control the revised thesis. This file prevents strong-sounding legacy claims from re-entering the V2 manuscript through old tables, appendices, or README text.

## Governing rule

> Legacy material is admitted by component, not by document.

A legacy manuscript can contain useful source locators and unusable claims at the same time.

## Migration map

## Legacy phrase quarantine

Canonical V2 files must not use the following as affirmative findings:

- `$185 billion unmeasured economy`
- `$82.8 billion invisible economy`
- `12.3x fiscal multiplier`
- `12.5x fiscal multiplier`
- `92% of activity missed`
- `5-6% of ASEAN GDP is unmeasured`
- `governments capture 0.6-3.4% of the invisible economy`
- `natural experiment validates the invisible economy`
- `audited data eliminates sampling error`
- `census-level estimate`
- `true total likely ...`

They may appear only in a clearly labeled history/critique section explaining why V2 rejected them.

## Root README warning

The existing legacy `IE-JDE/Invisible_Economy/README.md` on `main` still describes the old VoxEU-ready `$185B` package. Until the proposal is stable enough to update the top-level authority safely, reviewers working on V2 should treat this `rebuilt_2026/` directory as the research-control layer and the old README as historical.

Do not delete the old material yet: it contains provenance that may still be useful. Deprecation should precede archival deletion.
