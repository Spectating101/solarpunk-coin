# Self-hosted fonts

DM Sans, Instrument Serif and JetBrains Mono, as WOFF2 (Latin and Latin Extended subsets), copied from the
files Google Fonts publishes. Licensed under the SIL Open Font License 1.1.

The licence texts ship with the site at `third-party-notices.txt` (source: `frontend/public/`).
`../../styles/fonts.css` declares the `@font-face` rules; weights are variable ranges where the file is a variable font.
