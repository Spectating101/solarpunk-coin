# MILESTONES AND BUDGET

## Budget framing

This budget is milestone-based and tied to visible technical outputs.

## Baseline ask: $50,000

| Milestone | Deliverables | Budget |
|---|---|---|
| M1 Repo credibility | aligned README/status/docs, architecture pack, stale-claim cleanup | $8,000 |
| M2 External inspectability | Amoy deploy, addresses, explorer links, walkthrough proof | $14,000 |
| M3 Security readiness | audit-readiness pack, threat model, trust assumptions, remediation prep | $16,000 |
| M4 Pilot readiness | pilot-facing technical package and integration materials | $12,000 |

## Stretch ask: $75,000

Adds to baseline:

| Extension | Deliverables | Budget |
|---|---|---|
| Oracle/data hardening | stronger data quality checks and monitoring surface | $10,000 |
| Additional security depth | external review support and remediation bandwidth | $10,000 |
| Partner prototype polish | tighter demo and integration support for pilot conversations | $5,000 |

## Funding discipline

Funding is justified only if it accelerates:

1. public proof
2. security credibility
3. pilot conversion

No vague “general development” line items.
