# Master Submission Asset Register

**Status:** working register  
**Version:** 0.1  
**Date:** 2026-08-05

This register identifies the reusable assets from which all venue-specific packages are built. It records readiness and gaps without treating external recognition as the source of intrinsic programme value.

## Readiness scale

| Status | Meaning |
|---|---|
| **Authoritative** | frozen programme authority; derivatives must conform |
| **Strong** | usable now with bounded editing or verification |
| **Partial** | substantial content exists but material gaps remain |
| **Proposed** | identity is defined but the asset is not yet produced |
| **Blocked** | cannot be used until a stated dependency is resolved |

## Completion rule

An external package may reuse only assets marked **Authoritative** or **Strong**, unless the package explicitly labels a **Partial** asset and does not depend on it for the central claim.
