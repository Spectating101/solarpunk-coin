# ROADMAP

## Guiding rule

Do not optimize for grand narrative first. Optimize for external proof quality first.

## Milestone ladder

### Milestone 1: Repo credibility

- align README and status docs to current truth
- remove stale/contradictory claims
- provide clear architecture and scope docs

### Milestone 2: External inspectability

- deploy full stack to Polygon Amoy
- publish addresses and explorer links
- publish minimal interaction proof and walkthrough

### Milestone 3: Security credibility

- publish audit-readiness pack
- define threat model and trust assumptions
- start external audit process

### Milestone 4: Pilot credibility

- publish partner/pilot explainer
- define concrete pilot integration ask
- collect at least one partner yes/no response
